# User message

One user bubble. AgentPanel and AgentChatbox render `ChatUserMessage` for `role: "user"`. Long text expands and collapses.

## API

| Property | Description | Type | Default |
| --- | --- | --- | --- |

| `className` | Class on the bubble | `string` | — |
